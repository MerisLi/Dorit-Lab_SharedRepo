# Dorit-Lab_SharedRepo

This is a shared repository for all Dorit Lab members to upload lab data and collaborate on analysis in R.

1.  **Please create your own branch**!!!
2.  Please name your files properly (e.g. **experiment_strain_date**)
3.  Please save your files in the corresponding **folder** for the experiment you're running! Please feel free to create a folder for your experiment
4.  Remember to **pull** to keep up-to-date & **push** every time you finished your work
5.  Please **do not** delete others' work!!
